# 京东商品深度爬虫助手

一个专为Android设计的京东商品深度爬取应用，能够自动进入店铺中的每个商品详情页，提取完整的商品信息并生成Excel报告。

## 🚀 核心功能

### 深度爬取能力
- **智能页面识别**: 自动识别店铺页面、商品列表页、商品详情页
- **深度数据提取**: 逐个进入商品详情页，提取完整的商品参数
- **智能导航**: 安全的页面跳转和返回机制，防止导航丢失

### 全面数据收集
- **基础信息**: 商品标题、价格、店铺名称、商品链接
- **详细规格**: 品牌、型号、颜色、尺寸、材质等规格参数
- **销售数据**: 销量、评价数、库存状态、商品评分
- **图片信息**: 主图URL和详情图片链接

### 高级Excel导出
- **多工作表**: 基础信息、规格参数、数据分析分别存放
- **专业格式**: 自动格式化、颜色区分、边框样式
- **统计分析**: 价格分布、店铺统计、库存状态分析

## 📱 使用方法

### 1. 安装准备
1. 在Android设备上安装本应用
2. 确保已安装京东APP
3. 开启无障碍服务权限
4. 授予存储权限（用于保存Excel文件）

### 2. 开始爬取
1. **打开京东APP** - 进入想要爬取的店铺页面
2. **启动爬虫** - 在本应用中点击"开始爬取"
3. **自动运行** - 应用会自动识别商品并逐个进入详情页
4. **实时监控** - 查看爬取进度和收集到的商品数量
5. **完成导出** - 爬取完成后自动生成Excel文件

### 3. 文件管理
- Excel文件保存在: `/Android/data/com.jdcrawler.app/files/Documents/JDCrawler/`
- 支持一键分享功能，可以发送给其他应用

## 📊 Excel报告内容

生成的Excel文件包含三个工作表：

### 1. 商品基础信息
- 序号、商品标题、价格、店铺名称
- 商品链接、销量、评价数、库存状态
- 爬取时间戳

### 2. 商品规格参数
- 商品详细规格参数表
- 品牌、型号、颜色、尺寸等详细信息
- 按商品分组显示

### 3. 数据分析
- 商品总数统计
- 价格分布分析（平均价格、最高/最低价格）
- 店铺分布统计
- 库存状态分析
